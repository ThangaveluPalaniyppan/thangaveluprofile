# Thangavelu Palaniyappan — Senior Cloud Engineer Portfolio

A responsive static portfolio website designed for GitHub Pages.

## Files

- `index.html` — website content and structure
- `styles.css` — layout, responsive design and theme
- `script.js` — theme toggle and footer year

## Publish on GitHub Pages

1. Create a GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload these files to the repository root.
3. Commit the changes.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save.

Your site will be available at:

`https://YOUR-USERNAME.github.io/`

## Local preview

Open `index.html` directly in your browser, or run:

```bash
python -m http.server 8080
```

Then browse to `http://localhost:8080`.


## Images

The `images/` folder contains the professional portrait and recognition/training photographs supplied for the portfolio. Keep the filenames unchanged unless you also update `index.html`.

Place your final PDF CV in the repository root as `resume.pdf` to activate the **Download Resume** button.
